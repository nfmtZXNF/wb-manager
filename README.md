# 全局世界书管理

一个 SillyTavern（酒馆）第三方扩展：集中管理你的全局世界书。

## 功能

- 全局世界书管理面板（浏览、搜索、批量开关、拖拽排序、分组管理）
- 世界书快照：一键保存/恢复启用组合，支持角色专属快照和绑定聊天自动应用
- 原生世界书列表分组同步、悬浮快捷入口
- 导入角色卡时自动检测卡内世界书与本地书籍的差异

> 本扩展依赖「酒馆助手」提供的接口，请先安装并启用酒馆助手。

## 安装

酒馆 →「扩展」→「安装扩展」，粘贴仓库地址：

```
https://github.com/nfmtZXNF/wb-manager
```

国内网络访问 GitHub 困难的话，改用 Gitee 镜像地址（之后一键更新也走国内）：

```
https://gitee.com/nfmt/wb-manage
```

安装后刷新页面即可使用。

## 更新

检测到新版本时，「扩展」面板会出现更新提示，按提示一键更新即可。

## 反馈

扩展面板里有「建议 & Bug 反馈」入口，欢迎提交建议和问题；作者的回复会直接显示在反馈弹窗里。
